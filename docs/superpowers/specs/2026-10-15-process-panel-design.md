## 目标与范围

面向本机 Windows，提供可实际查询与操作的中文工具。进程数据来自操作系统，支持按端口号、PID、进程名搜索，并结束选定进程。项目独立存放于 `D:\yz2\process-panel`。

## 方案比较

1. **推荐：Python 本地服务 + 浏览器面板。** 使用 psutil 采集真实数据，前端采用 HTML、CSS、JavaScript。无需前端构建工具；提供双击启动脚本，自动打开浏览器。运行需要 Python 和一个 Python 依赖。
2. **Electron 桌面应用。** 能打包为独立桌面窗口，但体积和构建维护成本更高，不适合作为首版。
3. **PowerShell 原生窗口。** Windows 集成简单，但复杂筛选和大屏布局的体验及维护较弱。

## 页面与交互

- 中文深色控制面板，桌面宽屏布局，并兼容较小窗口。
- 顶部展示 CPU、内存、进程数、监听端口数及最近更新时间。
- “端口占用”展示协议、本地地址、端口、连接状态、进程名和 PID，支持 TCP / UDP 及监听状态筛选。
- “全部进程”展示进程名、PID、CPU、内存和已占用端口，支持排序及搜索。
- 搜索框支持端口号、PID 和进程名；提供清空、手动刷新和可暂停的自动刷新。
- 查看进程详情，展示可执行文件路径、启动时间及端口；无权限读取的字段明确显示。
- 结束进程前弹窗确认名称、PID 和端口，执行后刷新列表并反馈结果。
- 处理加载、无匹配结果、进程已退出、权限不足及服务失联等状态。

## 技术边界

- Python HTTP 服务仅监听 `127.0.0.1`；前端静态文件和 API 同源。
- psutil 采集系统资源、进程及 TCP / UDP 数据；定时采样并缓存快照，避免页面每次读取重复扫描系统。
- 进程查询、系统采集、HTTP 请求处理与前端交互分离，便于测试和维护。
- 操作接口校验本机来源和随机会话令牌。
- 结束进程时校验 PID 及启动时间，避免 PID 重用导致误操作；保护系统关键进程、工具本身及其启动进程。
- 不默认申请管理员权限；权限不足时提示可用管理员方式重启。
- 首版不包括远程主机管理、批量结束、服务启停、开机启动或历史监控。
