## 已执行验证

- Python unittest：30 项通过。覆盖真实 TCP / UDP 进程归属、进程详情、过期身份拒绝、受保护进程、结束后端口释放、接口令牌和来源校验、静态文件范围、窗口生命周期、剪贴板、全屏、实例唤起及 Windows 端口独占绑定。
- Node tests：12 项通过。普通查询按片段匹配端口、PID、进程名和地址，忽略大小写；`80` 可匹配 `8080` 与 `48080`，`:8080` 和 `pid:1234` 保留精确查询。另覆盖筛选、排序、分页和请求期间的确认框状态。
- EXE 独立运行：将本次打包文件单独复制到中文临时目录，移除 PATH 中的 Python 和 Python 环境变量，使用默认状态目录启动。通过 Win32 窗口句柄确认独立窗口实际显示，内置页面资源完整。
- 打包界面验证：仅为自动测试进程开启 Qt 调试接口，确认页面显示“实时连接”、CPU 数值已加载且初始加载提示消失；直接验证打包后的查询模块能够模糊查询和精确查询。普通启动不启用调试接口。
- 桌面生命周期：重复打开唤起已有窗口、最小化后恢复、运行记录缺失时仍可唤起；关闭后主进程、Qt 子进程和自身监听退出；两次同时重启仅产生一个窗口。
- 实际进程操作：校验测试子进程的 TCP / UDP 归属，结束该进程并重新绑定已释放端口；拒绝结束面板自身及其 Qt 渲染进程。
- 打包修正：隔离构建 PATH，避免收集开发工具目录中不兼容的 ICU DLL；核查打包依赖未包含该 DLL。Windows 服务使用独占绑定，首选端口已占用时改用空闲端口。
- 独立代码审查：桌面生命周期、互斥锁和本地 IPC、渲染进程保护、依赖收集与端口独占绑定均经复核，无未解决的重要问题。
- 最终交付验证：将通过验收的二进制复制到 `dist`，核对 SHA-256 一致；再次正常启动最终路径文件并重复打开，确认显示同一个桌面窗口。

验证环境为本机 Windows 11 x64。管理员提权环境的设置与恢复使用模拟 Win32 调用验证，未触发实际 UAC；未在其他 Windows 版本上实机验证。
