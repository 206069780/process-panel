# 使用指南

## 启动与退出

首次使用先解压 `Portside-windows-x64.zip`，在 `Portside` 文件夹中双击 `Portside.exe`，等待首次采集完成，窗口右上角会显示“实时连接”。程序在独立桌面窗口中运行。EXE 与 `_internal` 文件夹必须放在一起。

同一路径、同权限的 EXE 再次打开时，会恢复已有窗口。可以最小化、最大化，或按 `F11` 进入全屏；按 `Esc` 退出全屏。点击窗口关闭按钮会停止采集并退出程序。

启动时会显示带旋转光环和流动进度条的原生动画；页面加载完成后自动切换到工作台，没有额外的固定等待。点击启动画面右上角的关闭按钮可取消启动。

## 定位端口占用

1. 进入“端口占用”视图。
2. 输入端口号、PID、进程名或地址的片段；输入后立即过滤当前列表。
3. 按需选择 TCP / UDP、连接状态，或点击表头排序。
4. 点击进程名或“详情”，查看程序路径、启动命令、用户和占用端口。

默认状态为“监听 / 绑定”，包含 TCP 监听和 UDP 绑定。查看客户端连接或等待关闭的连接，需要选择“全部状态”。同一个进程可以占用多个端口，同一个端口也可能有多条地址或连接记录。

## 查询规则

| 输入 | 行为 |
| --- | --- |
| `80` | 片段匹配，可找到 `8080`、`48080`，以及 PID 或名称中包含 `80` 的行 |
| `NODE` | 忽略大小写，匹配包含 `node` 的名称 |
| `192.168` | 在端口视图中匹配本地或远端地址片段 |
| `:8080` | 只匹配本地端口 `8080` |
| `pid:1234` | 只匹配 PID `1234` |
| 空输入 | 显示当前协议和状态筛选条件下的全部结果 |

在“全部进程”视图中，普通查询匹配进程名、PID 和该进程的本地端口列表；`:8080` 可找到占用该端口的进程。地址匹配用于端口视图。查询会去除首尾空格，不支持正则、通配符或拼写纠错。

常用端口按钮使用精确查询。例如点击 `:3000` 等同于输入 `:3000`。“清除筛选”会清空查询并恢复默认协议和监听状态。

## 查看资源

顶部显示全机 CPU、内存、进程数，以及按“协议 + 端口”去重的监听端口数。端口表包含具体连接记录，因此其行数可能大于监听端口数。

“全部进程”中显示每个进程的 CPU 和内存占用；右侧列出内存占用最高的五个进程。CPU 首次采样可能为零，曲线只记录当前会话。显示为 `—` 的字段表示当前无法读取或没有数据。

页面默认每两秒更新。关闭“自动刷新”只暂停页面更新，后台仍采集；点击“刷新数据”可以立即请求一次新快照。关闭窗口才会停止采集。

## 结束进程

1. 通过名称、PID 和路径核对目标。
2. 点击“结束”，检查确认框中的进程名、PID 和端口。
3. 点击“确认结束进程”；程序会校验目标身份并刷新数据。

结束操作会终止整个进程，影响它占用的全部端口，也可能丢失未保存的工作。系统关键进程、面板自身、面板启动链中的进程及自身 Qt 渲染进程受到保护。

若程序由 Windows 服务、守护程序或开发工具自动重启，结束后可能出现新的 PID 并再次占用端口，应在对应服务或开发工具中停止它。某些连接可能保留 `TIME_WAIT` 状态，不代表原进程仍在运行。

## 常见问题

### 找不到端口或进程

先清除查询，检查协议和状态筛选；必要时切换“全部进程”。已退出的进程或尚未进入下一次采样的进程可能不在列表中。

### 提示权限不足

关闭程序后，右键 EXE 选择“以管理员身份运行”。管理员权限仍无法结束受到 Windows 保护的关键进程。

### 提示进程身份已变化

旧进程可能已退出，PID 已被另一个进程使用。刷新列表并重新核对目标后再操作。

### 启动慢或组件较多

推荐使用便携文件夹版。ZIP 只需解压一次，之后从解压后的目录启动，不要在压缩包预览中直接运行 EXE。程序包含 Python 和 Qt 渲染组件，运行时无需额外安装 Python 或 WebView2。

可选单文件版每次启动需要重新解包，启动速度较慢。若旧的桌面快捷方式仍指向单文件版，请改为解压目录内的 `Portside.exe`。

1.1.2 已优化采集及渲染组件加载顺序，保留原有界面。实际速度取决于磁盘、系统负载和缓存，见[实测记录](instant-startup-2026-10-15.md)。

### 程序启动端口被占用

内部服务默认尝试 `8765`，占用时自动选择空闲端口。用户通过应用窗口操作即可。

### 如何卸载

关闭程序后删除整个便携文件夹即可；单文件版只需删除 EXE。运行记录目录为 `%LOCALAPPDATA%\Portside\runtime`，可一并删除。源码运行时默认使用项目中的 `.runtime/`。
